# Issue tracker: Local Markdown

Issues and specs for this repo live as Markdown files in `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`
- The feature spec is `.scratch/<feature-slug>/spec.md`
- Child tickets live under `.scratch/<feature-slug>/issues/`
- Ticket files use `01-<slug>.md` numbering.
- Each issue contains a `Status:` line and may contain `Blocked by:`.
- Comments append under `## Comments`.

Wayfinder map operations use `.scratch/<effort>/map.md`; child tickets are files under `.scratch/<effort>/issues/`.

There is no external issue tracker configured for this repository.
