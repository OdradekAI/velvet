# UI Kit

UI Kit 是 Plugin Platform 的 UI 能力层。它服务于两个对象：

1. 受信任的 first-party extension，通过 React wrapper 共享宿主视觉和交互实现。
2. third-party isolated UI surface，通过 semantic component names、theme tokens 和 host requests 获得一致的宿主体验。

UI Kit 不拥有 Workbench layout、Overlay、Job 或核心数据。它把组件的语义、状态、动作、焦点和 accessibility contract 提供给宿主和插件 surface。
