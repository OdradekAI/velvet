# 无障碍

UI Kit 把键盘行为、focus model、selection owner、ARIA semantics 和 reduced motion 作为 contract 内容。

组件页应同时说明：

- native role 或 semantic role
- keyboard navigation
- focus entry 和 restoration
- disabled、busy、loading、empty 和 error state
- live region 和 retry behavior
- high contrast、density 和 reduced motion

真实 browser qualification 覆盖 portal、focus trap、focus restoration、native control semantics、ARIA labels 和 host projection keyboard behavior。动作清单见 [UI Kit action coverage](/reference/ui-kit/action-coverage)。
