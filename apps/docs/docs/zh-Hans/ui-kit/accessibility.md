# 无障碍

键盘行为、焦点模型、选区所有权、ARIA 语义和减少动态效果都是 UI Kit 契约的一部分。组件文档应说明：

- 原生或语义化角色；
- 键盘导航；
- 焦点进入与恢复；
- 禁用、忙碌、加载、空内容和错误状态；
- 动态播报区域与重试行为；
- 高对比度、密度和减少动态效果。

本地浏览器 fixture 覆盖 portal、焦点陷阱与恢复、原生控件、ARIA 标签和宿主投影的键盘行为，范围记录在 [UI 动作覆盖](/reference/ui-kit/action-coverage)中。Fixture 通过不代表所有支持平台上的读屏器或原生 OS/WebView 都已验证；参见[生态门禁](/reference/plugin-ecosystem-qualification)。
