# Accessibility

Keyboard behavior, focus model, selection ownership, ARIA semantics, and reduced motion are part of the UI Kit contract. Component pages should describe native or semantic roles, focus entry and restoration, live regions, retry behavior, high contrast, density, and reduced motion.

Browser qualification covers portal, focus trap, focus restoration, native control semantics, ARIA labels, and host projection keyboard behavior.
