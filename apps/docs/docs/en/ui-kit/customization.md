# Customization and theming

The public UI Kit customization surface is semantic tokens, density, contrast, reduced motion, and component variants. The UI Bridge sends a read-only `velvet.ui.theme/1` snapshot.

Component implementation tokens, Tailwind classes, font files, DOM structure, and Radix data attributes remain host-private.
