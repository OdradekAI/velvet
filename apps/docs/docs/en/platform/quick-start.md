# Quick start

The current platform is an Alpha contract. The shortest development path is:

1. Define a stable extension id and manifest version.
2. Declare contributions, target app, zone, and required capabilities.
3. Choose a host projection, trusted UI, or isolated UI surface.
4. Use host-registered Commands, Views, Preview providers, or Jobs.
5. Qualify success, failure, cancellation, and retry paths.

The Asset Inspector and Echo sidecar examples in `examples/plugins/` show the current runnable paths. The repository does not publish an external SDK package yet.
