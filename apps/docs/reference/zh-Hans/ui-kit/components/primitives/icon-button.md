# VelvetIconButton

IconButton 是 icon-first action。Props 包括 `icon`、必填 `label`、`disabled`、`busy`、`onClick`、`variant`、`apiVersion` 和 `testId`。

组件使用原生 button，Enter 和 Space 可激活，`label` 映射为 `aria-label`。完整 Demo 见 [IconButton API 与 Playground](/ui-kit/components/icon-button)。
