# VelvetSelect

Select 是带有宿主主题的原生 option 控件。公开 Props 包括 `children`、`value`、`defaultValue`、`onChange`、`multiple`、`disabled`、`busy`、`ariaLabel`、`describedBy`、`apiVersion` 和 `testId`。

组件保留 native option、Arrow key、表单提交和 multiple 语义，覆盖 default、focus、disabled 和 change。完整 Demo 见 [Select API 与 Playground](/ui-kit/components/select)。
