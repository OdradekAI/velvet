# VelvetCheckbox

Checkbox 是受控的布尔设置。公开 Props 包括 `checked`、`label`、`onCheckedChange`、`disabled`、`ariaLabel`、`describedBy`、`apiVersion`、`testId` 和 `className`。

组件覆盖 checked、unchecked、disabled、focus 和 toggle。它通过生成的 id 关联可见 label，键盘用户使用 Space 切换。完整 Demo 见 [Checkbox API 与 Playground](/ui-kit/components/checkbox)。
