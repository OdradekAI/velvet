# VelvetInput

Input 是带有宿主 density 和 focus styling 的原生文本输入。公开 Props 包括 `value`、`defaultValue`、`type`、`placeholder`、`disabled`、`busy`、`onChange`、`ariaLabel`、`describedBy`、`apiVersion` 和 `testId`。

组件覆盖 default、focus、disabled、busy 和 change。`busy` 会设置 busy 语义并禁止编辑。

完整 Demo、属性调试和无障碍说明见 [Input API 与 Playground](/ui-kit/components/input)。
